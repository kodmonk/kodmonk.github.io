Entrega de CMS empresarial

Kodmonk diseñó la biblioteca de componentes, fichas de diseño y integraciones CMS sin cabeza.

Alcance del equipo: Arquitectos frontend, diseñadores UI e ingenieros CMS.

Resultado medido
Contexto

Contexto

Un cliente de empresa necesitaba un sistema unificado de CMS y diseño para simplificar la publicación en múltiples portales de marca y aplicaciones web.

Desafío

Desafío

Mantener marcas consistentes, accesibilidad (WCAG AA), y rendimiento de componentes en diferentes pilas técnicas React y Angular.

Enfoque de Kodmonk

Enfoque de Kodmonk

  1. 01

    Construye un Sistema de Diseño Atómico centralizado con fichas de diseño marco-agnóstico.

  2. 02

    Ejecutados modelos de contenido CMS sin cabeza y ricos constructores de páginas visuales.

  3. 03

    Crear documentación de Storybook y tuberías automatizadas de pruebas de regresión.

Resultados

Resultados

  • Tiempo de creación de páginas web reducido de días a horas para editores de contenido.
  • Conseguido 100% consistencia de marca en 12 portales web distintos.
  • Completamente compatible WCAG 2.1 AA accesibilidad puntuación en todos los componentes web.
