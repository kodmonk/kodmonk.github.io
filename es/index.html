Tecnología

Stack tecnológico
Frontend

React, React Native, Next.js, TypeScript, Vue, Nuxt, Angular, Svelte, Vite, Tailwind CSS, shadcn/ui, Storybook, and Playwright for accessible interfaces, design systems, responsive portals, dashboards, and high-performance customer experiences.

Backend

Node.js, NestJS, Python, FastAPI, Django, PHP, Laravel, Java, Spring Boot, C#, .NET, Go, REST, GraphQL, tRPC, WebSockets, queues, webhooks, authentication, authorization, and event-driven workflows.

Data

PostgreSQL, MySQL, SQL Server, MongoDB, DynamoDB, Firestore, Supabase, Neon, PlanetScale, Redis, Kafka, Elasticsearch, OpenSearch, ClickHouse, BigQuery, dbt, and Airflow for reliable data systems and analytics.

Cloud

AWS, Azure, Google Cloud, Cloudflare, Vercel, Docker, Kubernetes, EKS, AKS, GKE, Cloud Run, ECS, Lambda, Helm, Terraform, Pulumi, serverless platforms, managed databases, networking, secrets, recovery, and cost-aware operations.

AI

OpenAI, Azure OpenAI, Anthropic, Gemini, Hugging Face, LangChain, LlamaIndex, Vercel AI SDK, RAG, vector search, pgvector, Pinecone, Weaviate, Qdrant, embeddings, document intelligence, evaluation, guardrails, and human approval workflows.

Delivery & Observability

GitHub Actions, GitLab CI, Azure DevOps, Jenkins, Buildkite, Argo CD, Sentry, Datadog, Grafana, Prometheus, OpenTelemetry, ELK, security scanning, automated testing, release controls, tracing, alerting, and incident readiness.
